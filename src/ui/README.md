# The HUD

What is written over the picture: your coordinates, your heading and the
hour; the prompt that says what a click would do; the tool bar; the buttons
along the edge; and the help panel (**H** or **?**), which is written from
the keys the features bind, so it lists every one of them.

## Files

```
index.js              plugs it into the game
hud.js                coordinates, prompts, tool bar, help panel, buttons
```
